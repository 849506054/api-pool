# 按成功请求次数轮换组成员

## 触发与参数

组字段 `rotate_requests` 为成功次数阈值，0 表示关闭，有效正值范围为 1–100000；缺省关闭态省略落盘键。`_on_success` 调 `_count_rotate_request` 累计成功次数，达标归零并调用 `_rotate_group_once`。失败尝试归故障路由，不计入成功阈值。

手动切换是当时的指针动作；配置的轮换继续在后续成功边界生效。路由与展示只读组当前指针。

## 名次与参与集合

`_rotate_group_once` 沿父组名次轴选择下一位，专用子组作为一档，成员可以是端点 ID 或子组名。组字段 `rotate_members` 为空/缺省表示全体，非空时仅在已选择成员间主动推进；兼容成员 ID、子组名和 `subgroup:<父组>:<子组>` 形式。

选择集同时检查当前成员和目标成员。当前成员属于集合且有另一可用目标才切换；当前成员在集合外、无可用目标、或仅当前成员可选时保持指针和 route epoch。计数达标与资格检查是两个步骤。

故障转移仍在完整组内候选环上进行，包含未参加主动轮换的端点；接手的非参与成员成功后保持当前指针，后续主动轮换资格检查保持其原位。冷却恢复、手动切换与组引用按各自契约改变指针。父轴和子组内先耗尽见 [子组契约](subgroup-join-main-contract.md)。

## 配置与页面

字段经组归一化、加载、create/update、`_sync_to_config` 和 `/api/groups` 接线，重启后读回已保存值。旧 `rotate_minutes` 按迁移路径清除，现行声明只使用成功次数。

成员控件默认折叠，展开时读取本组最新成员，`gmUpdateSummary` 联动次数与选择。次数 0/空显示「未启用」；启用后显示「全部/已选 N 个」。展开后按勾选保存，未展开保留已存集合；切开关保留选择。列表浮层与按钮同宽，固定高度内滚动，控件同行对齐。

本组启用且选择集非空时，选中成员显示轮换资格徽标。现行日志为 `成员轮换 '<当前成员>' → '<目标成员>'`；日志、请求成功次数和 route epoch 一起用于确认实际推进。

## 正式测试入口

`test/test_group_rotation.py` 覆盖次数、资格、指针、epoch、名次与持久化；`test/test_group_rotate_members.js` 覆盖控件和资格标记。报文变化同时核对 `test/test_group_idle_input.js` / `test/test_group_log_level.js` 的直接依赖断言。运行方式见 [testing](../testing.md)。
