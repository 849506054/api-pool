# UI 自动刷新机制

## 当前设计

API Pool 管理页面使用 **5 秒间隔**的 `setInterval(refresh, 5000)` 自动刷新端点列表、聚合池状态和切换链。

```javascript
refresh();
// 每5秒自动刷新状态（端点、聚合池、切换链）
setInterval(refresh, 5000);
// 日志保持单独轮询
setInterval(() => {
    loadChatLogs(chatLogsPage);
}, 3000);
```

## 历史

- **2026-07 之前**：全局定时刷新存在，后因某种原因被移除，注释为「移除全局定时刷新 — 只在需要时手动刷新」
- **2026-08-04**：恢复全局 5 秒刷新，原因是聚合池卡片状态不会自动更新，需要手动刷新页面才能看到端点健康状态变化

## 修改方式

所有改动在 `GUI_HTML` 常量末尾的 `<script>` 块中，`refresh()` 调用之后。具体位置在 `api_pool_server.py` 约 line 2970 附近。

## 注意事项

- 移除 `setInterval(refresh, ...)` 会导致聚合池卡片和切换链状态不自动更新
- 如果因为性能考虑想减少刷新频率，将 `5000` 改为 `10000` 或更大值即可
- 日志轮询（`loadChatLogs`）和状态刷新（`refresh`）是两条独立的定时器，互不影响
